# Report figures

Generated by `scripts/make_report_gifs.py`, `make_report_figs.py` and
`make_tracker_sidebyside.py`. Everything below uses the HC004 default session.

## Animations

Each one exists in three formats:

| Format | Use it for | Size |
|---|---|---|
| `.mp4` | **PowerPoint and slides.** H.264, 896x716, 61 frames | 1.7 – 3.2 MB |
| `.gif` | GitHub, Markdown, email. 576x460, 31 frames | ~4.5 MB |
| `.png` | Anywhere animation is not possible. The middle frame | ~0.3 MB |

Prefer the MP4 in slides: smaller file, twice the frames, sharper image. Drag it onto
the slide, then set Automatic and Loop under the Playback tab.

| File | Content | Report section |
|---|---|---|
| `01_gt_only` | Ground-truth boxes only | Step 2 |
| `02_gt_vs_yolo26` | Ground truth plus YOLO26 detections | Step 3 |
| `03_sort_gt` | SORT trajectories on ground truth | Step 5 |
| `04_jpdaf_gt` | JPDAF trajectories on ground truth | Step 5 |
| `05_full` | Everything at once: both box sets and both track sets | Step 6 |
| `09_sort_vs_jpdaf` | SORT and JPDAF side by side, trajectories accumulating over the full 899-frame clip | Step 8 |

## Still figures

| File | Content |
|---|---|
| `06_radar_gt` | Radar chart of the eight kinematic parameters, ground truth |
| `06_radar_yolo26` | The same chart computed from YOLO26 detections |
| `07_density_gt` | Density scatter of parameter pairs, ground truth |
| `07_density_yolo26` | The same, from YOLO26 detections |
| `08_layers` | Original, grayscale, binarized and normalized frames side by side |

`screenshots/` holds console and interactive-viewer captures taken during the work.

## Colour key

Green boxes are ground truth, red boxes are YOLO26 detections. Blue trails are tracks
derived from ground truth, orange trails are tracks derived from YOLO26 detections.

## Regenerating

```
call setup_env.bat
python scripts/make_report_gifs.py
python scripts/make_report_figs.py
python scripts/make_tracker_sidebyside.py
```

The last one re-runs SORT and JPDAF on the full clip, which takes a few minutes.
